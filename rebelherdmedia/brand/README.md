# Rebel Herd Media — brand assets (Open Water)

Identity: Direction A, Open Water. Lowercase `rebel herd.` in Fraunces (wght 600, opsz 72, SOFT 60), copper period, small MEDIA descriptor.

## Palette
| Role | Hex | Use |
|---|---|---|
| Deep charcoal | #1B2227 | text, primary buttons |
| Warm ivory | #F6F1E7 | page ground |
| Ocean teal | #0E5F6B | wordmark on light, links, secondary buttons |
| Lagoon teal | #4CC3BC | wordmark and links on dark grounds only — never as text on ivory |
| Copper | #B5673C | the period, one highlighted bar, step numbers (#D08A5E on dark) |
| Deep water | #14262B | dark band background |

## Files
- `rebelherd-wordmark-light.svg` / `-dark.svg` — full lockup with MEDIA. Letterforms are outlined paths (no font needed). The MEDIA label is live text in IBM Plex Sans; convert to outlines in Illustrator/Figma before sending to a printer.
- `*-nomedia.svg` — wordmark alone, for small headers.
- `*-mono-charcoal.svg` / `*-mono-ivory.svg` — one-color versions for embroidery, engraving, fax-grade print.
- `rebelherd-avatar-teal.svg` (default), `-deep.svg`, `-ivory.svg` — `rh.` short mark in a circle. Use teal for social profiles.
- `favicon.svg` — rounded-square short mark.
- `png/` — exports: wordmarks at 2400px wide (transparent and on deep water), avatars at 1024/400/180, favicons 512/192/32/16, `og-default.png` 1200×630.
- `Fraunces-RebelHerd-static.ttf` — the exact instance of Fraunces used, for proposals and documents. Fraunces is SIL Open Font License; free for commercial use.

## Rules
- Light ground → ocean wordmark, copper period. Dark ground → lagoon wordmark, copper (lifted) period.
- Minimum clear space around the wordmark: the height of the lowercase "r".
- Minimum size: wordmark 90 px wide on screen; below that use the `rh.` short mark.
- Don't recolor, outline, add effects, or set the name in another typeface.
